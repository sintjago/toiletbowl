# TOILETBOWL

Same toilet. Same angle. Many styles. No shit yet.

Style and camera are separate. Switching a style keeps the three-quarter closed-lid pose. More angles can be added later as new folders under `public/toilets/` plus a camera preset in `src/catalog.js`.

## Now

- **1 angle:** three-quarter, lid closed
- **59 styles:** photo, photo-derived filters, locked 3D copies, and painted/printed/crafted restyles of the same picture, plus cubism and isometric as best-effort extras
- **Flush:** every style plays the same handle / seat / lid / swirl / refill. Click the bowl, press Flush, or hit Space. Seat and lid hinge open from the back so the bowl is actually visible.

## Run

```bash
npm install
npm run dev
```

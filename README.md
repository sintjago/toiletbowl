# TOILETBOWL

Same toilet. Same angle. Many styles. No shit yet.

This repository is **toilets only**. Style and camera stay separate: switching a style keeps the three-quarter closed-lid pose. More angles can be added later as new folders under `public/toilets/` plus a camera preset in `src/catalog.js`.

The voxel matryoshka dolls are a **different project**. They must not merge into this tree. They currently live on `cursor/voxel-matryoshka-dolls-f981` / [PR #2](https://github.com/sintjago/toiletbowl/pull/2) and belong in their own repository.

## Now

- **1 angle:** three-quarter, lid closed
- **59 styles:** photo, photo-derived filters, locked 3D copies, and painted/printed/crafted restyles of the same picture, plus cubism and isometric as best-effort extras
- **Flush:** every style plays the same handle / lid / swirl / refill. Click the bowl, press Flush, or hit Space. The lid hinges open from the tank; the seat stays down so you can see into the bowl.
- **3D porcelain:** close-coupled sculpt — oval foot and stem, open rim, inner well, seat ring, domed lid, rounded tank, chrome trip lever, hinges, supply pipe — in a tiled bathroom.
- **Voxels:** a higher-res cubic toilet in that same room. Same three-quarter lock.

## Run
